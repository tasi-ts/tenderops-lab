# Source Code

This directory contains application source code for TenderOps Lab.

## Current service

```text
src/api
```

The API is a Java/Spring Boot service backed by PostgreSQL.

It demonstrates:

- REST API structure
- Maven build/test workflow
- PostgreSQL connectivity
- Flyway database migrations
- Spring Boot Actuator health and metrics
- Docker containerization
- Kubernetes deployment readiness

## Future services

Additional services may be added later, such as:

- background workers
- integration adapters
- scheduled jobs
- frontend/backend split examples

These are not implemented in the current version.
